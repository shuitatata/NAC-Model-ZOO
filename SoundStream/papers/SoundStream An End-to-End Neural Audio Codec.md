## Abstract
我们提出 SoundStream，一种新颖的神经音频编解码器，它能够高效地压缩语音、音乐和通用音频，其比特率通常是为语音定制的编解码器所针对的。 SoundStream 依赖于一个由全卷积编码器/解码器网络和残差向量量化器组成的模型架构，它们通过端到端的方式联合训练。 训练利用了文本到语音转换和语音增强领域的最新进展，这些进展结合了对抗性损失和重构损失，从而能够从量化嵌入中生成高质量的音频内容。 通过对量化器层应用结构化 dropout 进行训练，单个模型可以在 3 kbps 到 18 kbps 的可变比特率范围内运行，与在固定比特率下训练的模型相比，质量损失可以忽略不计。 此外，该模型适用于低延迟实现，支持流式推理，并能在智能手机 CPU 上实时运行。 在使用 24 kHz 采样率音频的主观评估中，3 kbps 的 SoundStream 优于 12 kbps 的 Opus，并接近 9.6 kbps 的 EVS。 此外，我们能够在编码器或解码器端执行联合压缩和增强，且不产生额外延迟，

## 1. Introduction
音频编解码器可以分为两大类：波形编解码器和参数编解码器。波形编解码器的目标是在**解码器端生成输入音频样本的忠实重构**。在大多数情况下，这些编解码器依赖于变换编码技术：一个（通常可逆的）变换被用来将输入时域波形映射到时频域。然后，对变换系数进行量化和熵编码。在解码器端，该变换被反转以重构时域波形。通常，编码器端的比特分配由感知模型驱动，该模型决定量化过程。一般而言，波形编解码器对音频内容的类型几乎没有或完全没有假设，因此可以处理通用音频。其结果是，它们在中到高比特率下产生非常高质量的音频，但在低比特率下运行时往往会引入编码伪影。参数编解码器旨在通过对要编码的源音频（在大多数情况下是语音）做出特定假设，并以描述音频合成过程的参数模型的形式引入强先验来克服此问题。编码器估计模型的参数，然后对这些参数进行量化。解码器使用由量化参数驱动的合成模型生成时域波形。与波形编解码器不同，其目标不是逐个样本获得忠实重构，而是生成感知上与原始音频相似的音频。

传统的波形和参数编解码器依赖于信号处理流水线和精心设计的选择，这些选择利用心理声学和语音合成领域的知识来提高编码效率。 最近，机器学习模型已成功应用于音频压缩领域，展示了数据驱动解决方案带来的额外价值 。 例如，可以将它们用作**后处理**步骤来提高现有编解码器的质量 。 这可以通过音频超分辨率（即扩展频谱带宽 [1]）、音频去噪（即消除有损编码伪影 [2]）或丢包隐藏 [3] 来实现 。

其他解决方案则采用基于机器学习的模型作为音频编解码器架构的组成部分 。在这些领域，文本到语音（TTS）技术的最新进展被证明是一个关键因素 。例如，最初用于从文本生成语音的强大生成模型 WaveNet [4] 被用作神经编解码器中的解码器 [5], [6] 。其他神经音频编解码器采用不同的模型架构，例如 LPCNet [7] 中的 WaveRNN 和 Lyra [8] 中的 WaveGRU，它们都针对低比特率语音 。

在本文中，我们提出了 SoundStream，这是一种新颖的音频编解码器，如图 1 所示，它可以比以前的编解码器更有效地压缩语音、音乐和通用音频 。SoundStream 利用神经音频合成领域的最新解决方案，并引入了一个新的可学习量化模块，以便在低到中等比特率下运行时提供高感知质量的音频 。图 2 展示了该编解码器的高层模型架构 。一个全卷积编码器接收时域波形作为输入，并以较低的采样率生成一系列嵌入，这些嵌入由残差向量量化器进行量化 。一个全卷积解码器接收量化的嵌入，并重建原始波形的近似值 。该模型使用重构损失和对抗性损失进行端到端训练 。为此，一个（或多个）判别器被联合训练，目的是区分解码音频和原始音频，并作为副产品，提供一个可以计算基于特征的重构损失的空间 。编码器和解码器都只使用因果卷积，因此模型的整体架构延迟仅由原始时域波形和嵌入之间的时间重采样率决定 。

![[SoundStream.pdf#page=1&rect=313,415,565,668|SoundStream, p.1]]![[SoundStream.pdf#page=2&rect=41,503,572,749|SoundStream, p.2]]总之，本文的主要贡献如下：
- 我们提出了SoundStream，这是一种神经音频编解码器，其中的所有组成部分（编码器、解码器和量化器）均以端到端的方式进行训练，并结合重构损失与对抗损失，以实现卓越的音频质量。
- 我们引入了一种新的残差向量量化器，并研究了其设计所涉及的码率-失真-复杂性之间的权衡。此外，我们还提出了一种创新的“量化器dropout”技术，用于训练残差向量量化器，从而使得单个模型可以处理不同的码率。    
- 我们证实了相比于使用梅尔频谱特征的方案，学习编码器能够带来非常显著的编码效率提升。  
- 我们通过主观质量指标的评估，表明SoundStream在宽广的码率范围内均优于Opus和EVS。
- 我们的模型设计支持流式推理，可以在低延迟下运行。部署到智能手机上时，可以在单个CPU线程上实现实时运行。
- 我们提出了一种SoundStream编解码器的变体，可同时进行音频压缩与增强，且不引入额外延迟。

## 3. Model

我们考虑一个单通道录音 $x \in \mathbb{R}^T$，以$f_s$为采样率。SoundStream 模型由一系列这三种 blocks 搭建，向图2中那样：
- encoder，将 $x$ 映射为一串 embeddings
- 一个残差向量量化器 (Residual Vector Quantizer)，它会用有限的codebooks中的若干个向量的和来替换掉 embedding 向量
- decoder，用于从量化的 embedding 中生成有损失的重建音频 $\hat x \in \mathbb{R}^{T}$
模型利用一个 discriminator 来进行端到端的训练，使用对抗损失和重建损失。可以可选地增加一个条件信号，用于控制是否为 encoder 或 decoder 启用降噪。

### A. Encoder architecture
![[SoundStream.pdf#page=4&rect=46,466,569,752|SoundStream, p.4]]
Encoder 的结构如图3，与 streaming SEANet encoder 的结构相同，只不过去掉了 skip connections。Encoder 包括一个 1D 卷积层（$C_{enc}$ 个通道），随后跟着 $B_{enc}$ 个卷积模块。每一个模块包含3个残差单元——每个残差单元分别包括扩张率为1、3、9的空洞卷积，随后跟着一个跨步卷积形式的下采样层。从 $C_{enc}$开始，每一次经过下采样，通道数都加倍。最后一个卷积核大小为3，步长为1的 1D 卷积用于将 embedding 的维度设置为 $D$。为了保证实时的推理，所有的卷积层都是 causal 的。这意味着在训练和离线推理中，所有的 padding 都被用于过去而不是未来，同时在流式推理中不使用 padding。我们使用 ELU，并且不使用任何归一化。卷积块的数量 $B_{enc}$ 和 相应的步长序列决定了 input 流和 embeddings 之间的时间重采样率。例如，当 $B_{enc}=4$，且使用 $2,4,5,8$ 作为步长时，每一个 embedding 会对应 $M = 2\cdot 4\cdot 5\cdot 8=320$个输入样本点。因此，编码器的输出 $enc(x) \in \mathbb{R}^{S\times D}$，其中 $S = T/M$ 

### B. Decoder architecture
解码器采用了类似的架构。一个 1D 卷积层，随后跟着 $B_{enc}$ 个卷积块。decoder 块是 encoder 块的镜像，包括一个反卷积用于上采样，跟着3个残差单元。我们使用和encoder中相同的步长，但是顺序相反，来重建和 input 有着相同分辨率的波形。每次上采样时，通道数减小一半，因此最后一个 decoder 块会正好输出 $C_{dec}$ 个通道。最后一个具有一个滤波器，卷积核大小为7，步长为1的 1D 卷积层负责将 embeddings 投影回波形域以产生 $\hat x$。在图3中，编码器和解码器的通道数由同一个参数控制，即$C_{enc}= C_{dec}=C$。我们同样探索了 $C_{enc}\neq C_{dec}$ 的情况，这会导致计算上更轻量或更重量的Encoder，Decoder。

### C. Residual Vector Quantizer:
Quantizer 的目标是压缩 encoder 的输出 $enc(x)$ 到目标比特率 R，用 bits/second (bps)表示。为了端到端地训练 SoundStream，Quantizer 需要与 encoder、decoder 联合起来反向传播。在 VQ-VAE 的背景下，文献 [31], [32] 中提出的 vector quantizer 满足了这一要求。这一 vector quantizer 学习一个由 N 个向量组成的 codebook，来 encoder $enc(x)$ 中的每个 D 维帧。编码后的音频 $enc(x) \in \mathbb{R}^{S\times D}$ 随后被映射到一串 one-hot 向量，shape为$S \times N$ ，可以用 $S \log_{2}N$ 个 bit 来表示。

**Limitations of Vector Quantization**: 举一个具体的例子，让我们考虑一个目标为 $R = 6000 bps$ 的编码器。当使用步长因子 $M = 320$ 时，采样率为 $fs = 24000 Hz$的原始音频的每一秒钟会被表示为encoder输出的 $S=75$ 帧。这意味着每一帧内包含 $r = \frac{6000}{75}= 80$ 个 bits。使用一个平凡的 vector quantizer，这需要一个有 $N=2^{80}$个向量的 codebook，这是非常不现实的。

**Residual Vector Quantizer**: 为了解决这一问题，我们采用了 Residual Vector Quantizer （残差向量量化器，也叫作 multi-stage vector quantizer，多阶段向量编码器），它以如下方式层叠 $N_q$ 层 VQ：未经过量化的输入向量首先被传进第一个 VQ 中，同时会被计算量化残差（其实就是量化误差）。这个残差随后被一系列 $N_{q}- 1$ 个 VQ 迭代量化，如算法 1中所示。总预算码率被均匀分配给每个 VQ，也就是说，$r_{i}= \frac{r}{N_{q}}= \log_{2}N$。例如，当使用 $N_{q} = 8$的残差量化器时，每个量化器使用一个大小为 $N = 2^{\frac{r}{N_{q}}}= 2^{\frac{80}{8}} = 1024$ 的 codebook。对于一个目标比特率$r$，参数$N_q$控制计算复杂度和编码效率之间的平衡，我们在随后的V-D中探究了这一点。

![[SoundStream.pdf#page=4&rect=45,310,309,456|SoundStream, p.4]]
每一个 quantizer 的 codebook 使用指数移动平均来更新，跟随 VQ-VAE-2中的方法。为了提升 codebooks 的利用率，我们采用了两个额外的方法。首先，我们在第一个 batch 使用了 $k-means$ 算法，并用学到的质心来初始化，而不是随机初始化。这让 codebook 能够接近输入的分布，并提高它的利用率。其次，如 [34] 提到的那样，当 codebook 中的某个向量在若干个 batch 中没有被分配到任何一个 input 帧的时候，我们使用当前 batch 内随机采样的一个输入帧替换它。更准确滴说，我们统计每个向量分配的指数移动平均值（衰减因子为 0.99 ），并替换掉该平均值低于2的向量。

**Enabling bitrate scalability with quantizer dropout**: RVQ 提供了一个方便的框架来控制比特率。对于每个码本的固定大小 $N$，VQ的层数 $N_{q}$ 决定了比特率。因为 VQ 与 encoder/decoder 联合训练，理论上需要为每一个目标比特率训练一个不同的 SoundStream 模型。然而，拥有一个可以在多个目标比特率下工作的 可变比特率 模型是更可行的，因为这减少了在encoder和decoder端用于储存模型参数所需要的内存占用。

为了训练一个这样的模型，我们按照如下方式修改了算法1: 对于每一个输入样本，我们从$[1;N_{q}]$中均匀随机采样 $n_{q}$，并且只使用前 $n_{q}$ 个量化器。这可以看作是一种用于量化层的结构化 dropout。因此，模型被用于训练编码和解码所有比特率在 $n_{q}= 1\dots N_{q}$ 对应的范围内的音频。在推理过程中，实际的 $n_{q}$ 根据需要的比特率来选取。先前的神经网络压缩模型依赖于 product quantization （乘积量化），或者是多个 VQ 层的输出的拼接 (concatenate)。在这些方法中，改变比特率要么需要改变 encoder 和/或 decoder 的结构（因为维度会改变），要么需要重新训练一个合适的 codebook。 RVQ 的一个关键优势就是 embeddings 的维度不会随着比特率改变。而是在保证维度不变的同时，通过对每一个VQ层的结果进行加性组合来细化量化embeddings。因此，不需要通过改变encode和decoder的任何结构来适应不同的比特率。在V-C节中，我们展示了这种方法允许只训练一个 SoundStream 模型，其性能能够匹配对不同比特率专门单独训练的模型。

### D. Discriminator arhitecture
为了计算E中描述的重建损失，我们定义了两个不同的discriminator：1. 一个基于波形的discriminator，接受一个单一的波形作为输入。2. 一个基于STFT的discriminator，接受输入波形的STFT复数值作为输入，以实部和虚部表示。因为两个discriminator都是完全由卷积构成的，输出的logits数量与输入音频的长度成比例。

对于基于波形的discriminator，我们使用[15]中提出，被[45]采用的多分辨率卷积discriminator。三个结构相同的模型以不同的分辨率用于输入音频：原始分辨率，2倍下采样和4倍下采样。每一个单一尺度discriminator由一个初始的普通卷积和随后的四个分组卷积组成，每一个分组卷积的组大小为4，下采样因子为4，通道乘数为4，最多有1024个输出通道。随后是两个普通卷积来产生最后的输出，即logits。

![[SoundStream.pdf#page=5&rect=310,434,570,745|SoundStream, p.5]]

基于STFT的discriminator的结构如图4，在单一尺度上运行。计算STFT时，窗口长度为1024个样本点，步长为256个样本点。跟在STFT层后的是一个2D卷积层（卷积核大小为$7\times 7$，32通道）。随后是一组残差块，每个残差块起始是一个 $3\times 3$ 卷积，然后是一个 $3\times 4$或$4\times 4$卷积，步长是$(1,2)$或$(2,2)$，其中$(s_{t}, s_{f})$分别指时间维度和频率维度的下采样因子。我们交替使用$(1,2)$和$(2,2)$的步长，总共6个残差块。通道数随着网络的深度逐渐变多。在最后一个残差块的输出端，激活的形状为 $T / (H\cdot 2^{3}) \times F / 2^{6}$，其中T是时间域样本点的数量，$F = W / 2$ 是频率bin（频率箱？）的数量。最后一层通过一个全卷积层（实现为 $1\times F / 2^{6}$ 卷积）聚合下采样后所有 frequency bins的logits，来在下采样后的时间域产生一个1维的信号。

### E. Training objective
令$G(x) = dec(Q(enc(x)))$ 表示 SoundStream生成器，它通过encoder、quantizer和decoder对输入波形$x$进行处理，记$\hat x = G(x)$ 表示解码后的波形。我们通过一个混合损失来训练SoundStream，以同时满足信号重建保真度和感知质量，这符合[46]中的感知-失真权衡原则。

对抗损失用来提升感知质量，它被定义为discriminator的logits上的hinge loss，并在多个discriminator和时间上取平均。更正式地，令$k \in {0, \dots, K}$ 表示不同discriminators的序号，其中$k=0$ 表示基于STFT 的 discriminator，$k \in {1, \dots, K}$ 表示不同分辨率的基于波形的discriminator。令 $T_k$ 表示第k个discriminator的logits输出在时间上的长度。Discriminator通过最小化以下的损失函数来进行训练，以区分原始和重建后的音频：
$$
		L_{D}= E_{x}\left[\frac{1}{K} \sum\limits_{k} \frac{1}{T_{k}} \sum\limits_{t}\max(0, 1-D_{K,t} (x))\right]+ E_{x}\left[\frac{1}{K} \sum\limits_{k} \frac{1}{T_{k}}\sum\limits_{t} \max\left(0, 1 + D_{k,t} (G(x))\right) \right]
$$
而生成器的对抗损失为:
$$
	L_{G}^{adv} = E_{x} \left[\frac{1}{K} \sum\limits_{k,t} \max (0, 1-D_{k,t} (g(x)))\right]
$$

为了提升解码信号$\hat x$相对于原始信号$x$的保真度，我们采用了两个额外的损失：1. 一个“特征”损失 $L_{G}^{feat}$，他在由判别器定义的特征空间计算。2. 一个多尺度频谱重建损失 $L_{G}^{rec}$。

更具体地，“特征”损失是计算生成音频和相对应的真实音频在discriminator内部层输出的平均绝对值差异。
$$
L^{feat}_{G}= E_{x}\left[ \frac{1}{KL} \sum\limits_{k,l} \frac{1}{T_{K,L}}\sum\limits_{t} |D_{k,t}^{l}(x) - D_{k,t}^{l}(G(x))|\right]
$$
其中 L 是内部层的数量，$D_{k,t}^{l}(l \in {1, \dots, L})$ 是第k个discriminator第l层的第t个输出，$T_{k,l}$指这一层在时间维度上的长度。

多尺度频谱重建损失按照如下具体描述：
$$
L_{G}^{rec} = \sum\limits_{s\in2^{6},\dots,2^{11}}  \sum\limits_{t} ||S^{s}_{t}(x) - S_{t}^{s}(G(x))|_{1}+ \alpha_{s}\sum\limits_{t} ||\log S_{t}^{s}(x) - \log S_{t}^{s}(G(x))||_{2}
$$
其中 $S_{t}^{s}(x)$ 表示 使用窗口长度为$s$、跳跃步长为$s/4$ 计算得到的 64-bin 梅尔频谱的第t帧。我们令 $\alpha_{s} = \sqrt{s/ 2}$ 。

完整的生成器损失是不同损失组分的加权平均：
$$
L_{G}= \lambda_{adv} L_{G}^ {adv} + \lambda_{feat}\cdot L_{G}^{feat} + \lambda_{rec}\cdot L_{G}^{rec}
$$
在所有的实验中，我们设定 $\lambda _{adv} = 1$，$\lambda _{feat}= 100, \lambda _{rec}= 1$

### F. Joint compression and enhancement
在传统的音频处理流水线中，压缩和增强通常由不同的模块执行 。例如，可以在发送端，在音频被压缩之前应用音频增强算法，或者在接收端，在音频被解码之后应用 。在这种设置中，每个处理步骤都会增加端到端延迟，例如，由于需要将输入音频缓冲到由所采用特定算法确定的预期帧长度 。相反，我们设计 SoundStream 的方式使得压缩和增强可以由同一模型联合执行，而不会增加整体延迟 。增强的性质可以由训练数据的选择来决定 。作为一个具体的例子，在本文中，我们展示了将压缩与背景噪声抑制相结合是可能的 。

更具体地说，我们以这样一种方式训练模型：通过输入一个表示两种模式（启用去噪或禁用去噪）的条件信号，可以在推理时灵活地启用或禁用去噪 。为此，我们准备的训练数据包含以下形式的元组：（inputs, targets, denoise）。当 denoise 为假时，targets = inputs；当 denoise 为真时，targets包含相应inputs的纯净语音部分 。因此，如果条件信号被禁用，网络被训练来重构带噪语音；如果启用，则被训练来产生带噪输入的纯净版本 。请注意，当 input 由纯净音频（语音或音乐）组成时，targets = inputs，并且 denoise 可以为真也可以为假 。这样做是为了防止 SoundStream 在启用去噪时对纯净音频产生不利影响 。

为了处理条件信号，我们在残差单元之间使用 Feature-wise Linear Modulation（逐特征线性调制）层 [49]，这些层将网络特征作为输入并按如下方式对其进行转换 ：
$$
\tilde \alpha_{n,c} = \gamma_{n,c} a_{n,c} + \beta_{n,c}
$$
其中 $a_{n,c}$ 是通道 c 的第n个激活值。系数 $\gamma_{n,c}$ 和 $\beta_{n,c}$ 由一个线性层计算得出，该线性层接收一个（可能随时间变化的）二维 one-hot 编码作为输入，该编码决定了去噪模式 。这使得可以随时间调整去噪级别 。

原则上，FiLM 层可以在编码器和解码器架构的任何位置使用 。然而，在我们的初步实验中，我们发现在编码器或解码器侧的瓶颈处应用条件（如图 3 所示）是有效的，并且通过在不同深度应用 FiLM 层没有观察到进一步的改进 。在第 V-E 节中，我们从音频质量和比特率两方面量化了在编码器或解码器侧启用去噪的影响 。
